ARANDU · SISTEMA DO DOJO — BUILD PÚBLICA
Versão 2.81 · novembro de 2026

Sistema de gestão para dojo de jiu-jitsu: alunos, frequência, treinos, mensalidades, despesas e relatórios. Funciona em navegadores de computador e celular.

PRIVACIDADE
Esta build não contém a base real de alunos; ela começa com dados demonstrativos. Dados inseridos ficam no navegador deste dispositivo, a menos que o responsável configure sincronização externa. Não publique backups JSON com dados pessoais.

PUBLICAÇÃO
Publique esta pasta completa em um serviço de hospedagem estática com HTTPS, como GitHub Pages. O ponto de entrada é index.html. Preserve também sw.js, manifest.webmanifest e a pasta assets/ para os recursos PWA.

RECURSOS
- Cadastro, busca e filtros de alunos.
- Chamada por turma, seleção de data e visitas.
- Gráficos de frequência em percentual ou números absolutos.
- Financeiro e relatórios gerenciais.
- Tema Dark/Light e paletas personalizáveis. A paleta Dojo foi mantida; as demais foram renovadas com inspiração em A Dictionary of Color Combinations, de Sanzo Wada.
- Atalho PWA e suporte offline quando hospedado corretamente.
- Sincronização Supabase opcional, a configurar pelo responsável pela instalação.
