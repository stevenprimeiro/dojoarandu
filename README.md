# Arandu · Sistema do Dojo — versão pública

**Versão:** 2.85 · novembro de 2026

Sistema de gestão para dojo de jiu-jitsu: alunos, frequência, treinos, mensalidades, despesas e relatórios. Funciona no navegador em computador e celular. A build pública usa uma base demonstrativa, sem dados reais de alunos.

## Publicar

Publique o conteúdo desta pasta no GitHub Pages ou em outro serviço de hospedagem estática com HTTPS. O arquivo de entrada é `index.html`; mantenha junto os demais arquivos, especialmente `sw.js`, `manifest.webmanifest` e `assets/`.

Também é possível usar o pacote `DojoArandu v2.81p.zip`, que contém os arquivos necessários ao deploy e estes READMEs.

## Recursos

- Cadastro, busca e filtros de alunos, com faixa e graus.
- Chamada por turma, seleção de data e registro de visitas.
- Gráficos de presença em percentual ou números absolutos.
- Controle financeiro e relatórios gerenciais.
- Tema Dark/Light e paletas personalizáveis. A paleta Dojo foi preservada; as demais combinações foram renovadas com inspiração em *A Dictionary of Color Combinations*, de Sanzo Wada.
- Instalação como atalho PWA e suporte offline no navegador, quando hospedado corretamente.
- Armazenamento local no navegador; sincronização Supabase é opcional e precisa ser configurada pelo responsável pela instalação.

## Privacidade e segurança

Esta distribuição pública não contém a base real de alunos: inicia com dados demonstrativos. Dados que você inserir no navegador ficam nesse dispositivo, salvo se configurar um serviço externo. Não publique backups JSON com informações pessoais.

A pasta publicada inclui os ícones e arquivos necessários. O arquivo `DojoArandu v2.85p.html` é uma cópia do `index.html` com nome versionado.
